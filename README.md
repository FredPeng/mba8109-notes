# MBA 8109 Research Methods

研究方法 — 课堂笔记（Strathmore Business School, MBA）

## 内容

- **index.html** — 可在浏览器中打开的交互式笔记网页，支持在线编辑、本地保存、导出
- 课上使用的 PDF / PPTX 原始资料也放在本目录下

## 使用方法

1. 直接用浏览器打开 `index.html`
2. 点击「✏️ 进入编辑模式」可修改内容
3. 修改会自动保存到浏览器 localStorage（编辑模式下每 30 秒自动保存）
4. 可点击「📥 导出 HTML」下载到本地
