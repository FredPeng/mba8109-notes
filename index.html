    一、研究的本质（Introduction to Research）

    核心概念

    • 研究（Research）：为回答问题或解决问题而进行的系统性、有目的的探究过程。
    • 基础研究 vs 应用研究：前者扩展知识本身，后者解决具体的管理/组织问题。
    • 科学研究的特征：目的性、严谨性、可检验性、可重复性、精确与可信、客观性、可推广性、简约性。
    • 演绎 vs 归纳：演绎（理论 → 假设 → 数据 → 检验）；归纳（数据 → 模式 → 理论）。
    待补充：课上给出的定义、例子与考点。

    二、研究哲学与范式（Research Philosophy & Paradigms）

    范式本体论 Ontology认识论 Epistemology典型方法
    实证主义 Positivism客观、单一现实可观测、可测量的事实定量、假设检验、调查问卷
    解释主义 Interpretivism现实由主体建构主观意义、情境化理解定性、访谈、民族志
    批判实在论 Critical Realism现实存在但只能间接观察需透过机制解释表象混合、案例研究
    实用主义 Pragmatism取决于研究问题以「有用」为标准混合方法 Mixed Methods
    待补充：讲师强调的范式与研究设计之间的对应关系。

    三、研究问题与研究目标（Research Problem, Objectives & Questions）

    • 研究缺口（Research Gap）：现有文献未解答、结论矛盾或情境未覆盖之处。
    • 问题陈述（Statement of the Problem）：现状 → 理想状态 → 差距 → 后果 → 因此需要研究。
    • 研究目标：一般目标（General Objective）+ 若干具体目标（Specific Objectives），须可测量。
    • 研究问题 / 假设：每个具体目标对应一个研究问题或假设（H₀ / H₁）。
    • 研究的意义（Significance）与范围（Scope & Limitations）。
    待补充：课上的问题陈述写作模板与示例。

    四、文献综述（Literature Review）

    • 目的：界定概念、发现缺口、建立理论基础、避免重复、支撑方法选择。
    • 结构：引言 → 理论综述（Theoretical Review）→ 实证综述（Empirical Review）→ 概念框架 → 文献缺口小结。
    • 理论框架 vs 概念框架：理论框架来自既有理论；概念框架是自变量、因变量、中介变量、调节变量之间的关系图。
    • 引用规范：APA 7th（课程常用），注意抄袭（Plagiarism）与 Turnitin 相似度要求。
    待补充：讲师要求的文献数量、年限与引用格式细则。

    五、研究设计（Research Design）

    类型用途常见做法
    探索性 Exploratory问题尚不清晰访谈、焦点小组、文献
    描述性 Descriptive刻画现象「是什么」横断面调查 Survey
    解释性 / 因果 Explanatory检验变量间因果实验、回归分析
    纵向 Longitudinal随时间变化面板数据、追踪研究

    其他维度：定量 / 定性 / 混合方法；横断面 vs 纵向；实验室 vs 实地；干预程度与研究情境。

    待补充：课上讲的设计选择逻辑与案例。

    六、总体与抽样（Population & Sampling）

    • 总体 / 目标总体 / 抽样框（Sampling Frame）/ 样本单位。
    • 概率抽样：简单随机、系统、分层（Stratified）、整群（Cluster）、多阶段。
    • 非概率抽样：便利、判断/立意（Purposive）、配额、雪球。
    • 样本量确定：Yamane、Cochran、Krejcie & Morgan 表；考虑置信水平、误差、总体方差、回收率。
    Yamane（有限总体）：n = N / (1 + N·e²)　　例：N = 1000, e = 5% → n = 1000 / (1 + 1000×0.0025) = 286
    Cochran（大总体，比例）：n₀ = Z²·p·q / e²　　p = 0.5, Z = 1.96, e = 5% → n₀ ≈ 384
    待补充：课上使用的公式版本与计算例题。

    七、测量与量表（Measurement & Scaling）

    • 四种测量尺度：名义（Nominal）、序数（Ordinal）、等距（Interval）、等比（Ratio）—— 决定可用的统计方法。
    • 操作化（Operationalization）：抽象概念 → 维度 → 具体指标 → 问卷题目。
    • 量表类型：Likert、语义差异（Semantic Differential）、Stapel、等级排序、固定总和。
    • 效度（Validity）：内容效度、表面效度、构念效度（收敛/区分）、准则效度；内部效度 vs 外部效度。
    • 信度（Reliability）：Cronbach's α（≥0.7 可接受）、重测信度、折半信度、评分者间信度。
    待补充：课上对 α 阈值与效度检验步骤的具体要求。

    八、数据收集方法（Data Collection）

    • 一手数据：问卷（自填/访员）、访谈（结构化/半结构化/深度）、焦点小组、观察、实验。
    • 二手数据：公司报表、行业报告、政府统计、数据库；优点是省时省钱，缺点是契合度与时效。
    • 问卷设计：避免双重问题、引导性提问、专业术语；注意题序、过滤题、预调查（Pilot Test）。
    • 回收率与无应答偏差（Non-response Bias）处理。
    待补充：课上示范的问卷片段与常见错误。

    九、数据处理与分析（Data Analysis）

    定量分析

    • 数据准备：编码、录入、清洗、缺失值与异常值处理、反向计分。
    • 描述统计：频数、均值、中位数、标准差、偏度与峰度。
    • 推断统计：t 检验、方差分析 ANOVA、卡方检验、相关分析（Pearson / Spearman）。
    • 回归：简单与多元线性回归；R²、F 检验、t 检验、β 系数；假设检验（线性、正态、同方差、无多重共线性 VIF < 10、无自相关 Durbin-Watson）。
    • 工具：SPSS / Excel / Stata / R。

    定性分析

    • 内容分析（Content Analysis）、主题分析（Thematic Analysis）、编码（开放 → 主轴 → 选择性）、扎根理论。
    • 可信度标准：可信性、可迁移性、可靠性、可确认性（Trustworthiness 四要素）。
    待补充：课上使用的软件操作步骤与输出解读。

    十、研究伦理（Research Ethics）

    • 知情同意（Informed Consent）、自愿参与、匿名与保密、不伤害原则。
    • 数据的安全存储与使用限制；利益冲突披露。
    • 学术诚信：抄袭、数据造假、重复发表；引用规范。
    • 审批流程：机构伦理委员会（IRB / Ethics Review）、研究许可（如 NACOSTI 许可，肯尼亚）。
    待补充：学校对伦理审批与研究许可的具体要求。

    十一、研究计划书与报告写作（Proposal & Report Writing）

    研究计划书常见结构

    1. 封面、摘要、目录
    2. 第一章 引言：背景、问题陈述、研究目标、研究问题/假设、研究意义、范围与局限
    3. 第二章 文献综述：理论综述、实证综述、概念框架、文献缺口
    4. 第三章 研究方法：研究设计、总体与抽样、数据收集工具、效度与信度、数据分析方法、伦理考量
    5. 参考文献（APA）、附录（问卷、时间表、预算）

    最终报告在此基础上增加：第四章 结果与讨论、第五章 结论与建议。

    待补充：讲师给出的模板、页数与格式要求。
